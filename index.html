留学生 成績処理ナビ

学校暦が初期値（仮の例）のままです。「学校暦設定」で実際の日程に直すと、休業期間や試験期間の判定が正確になります。

出発日・帰国日の一覧（CSV）を読み込むと、全員分を一度に判定します。

列：氏名, 出発日, 帰国日（日付は 2026-07-25 や 2026/7/25 の形式）。任意で「期末受験」列（全/未）。Excelで保存したCSV（Shift_JIS）もそのまま読めます。

個別判定で保存した生徒の一覧です。どのパソコンからでも見られます。

氏名などの個人情報は、非公開(Private)のリポジトリにだけ保存します。公開(Public)のリポジトリには保存できません。

学期と試験の日程を年度ごとに入力します。休業期間や試験期間の判定に使います。

入力内容はこのブラウザに自動保存されます。学校全体で共有する場合は「書き出し」したJSONを共有するか、js/calendar-default.js を書き換えてください。

GitHubで共有する（どのパソコンからでも同じ学校暦に）

アクセストークンの作り方（最初の1回だけ）
  1. GitHubの右上のアイコン → Settings → 左下の Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Token name：ryugaku-seiseki／Expiration：1年など
  3. Repository access：Only select repositories → このアプリのリポジトリだけを選ぶ
  4. Permissions → Repository permissions → Contents を Read and write にする
  5. Generate token を押し、表示された github_pat_… をコピーして上の欄に貼る（この画面は一度しか出ません）
トークンは、入力したパソコンのこのブラウザにだけ保存されます。学校の共用パソコンでは、使い終わったら「トークンを消す」を押してください。トークンは他人に見せたり、チャットに貼ったりしないでください。
