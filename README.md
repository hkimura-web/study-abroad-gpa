# 留学生 成績処理ナビ

「アウトバウンド留学生徒の成績処理早見表」を、出発日・帰国日を入れるだけで当てはめられるようにしたアプリです。
サーバー不要の静的ページ（HTML/JS）で、生徒の情報はブラウザの外へ送信・保存されません（学校暦のみブラウザに保存）。

## 使い方
- 個別判定：出発日・帰国日を入力 → 型（長期A/B、短期A/B/C-1/C-2/D、E）、Blend入力の指示、学年成績の扱い、該当行を強調した原表を表示。印刷／PDF保存はブラウザの印刷から。
- CSV一括判定：氏名,出発日,帰国日 のCSVを読み込み（Excel保存のShift_JISも可）。結果をCSVで保存できます。
- 学校暦設定：学期・中間/期末試験の日程を年度ごとに入力（初期値は仮の例）。

## 構成
- `js/rules.js` 早見表のデータ（表を改訂するときはここだけ編集）
- `js/logic.js` 日付→型の判定
- `js/calendar-default.js` 学校暦の初期値
- `tests/logic.test.js` `node tests/logic.test.js` で判定のテスト

## GitHubで公開
1. このフォルダをリポジトリにして `main` にpush
2. Settings → Pages → Source を「GitHub Actions」にする
3. 以後、pushのたびに自動公開されます（`.github/workflows/pages.yml`）

## 判定のしくみ
出発日・帰国日を「学期×中間/期末」の区間に変換し、組合せで型を決めます。休業期間（夏休み等）の日付は前後どちらの区間にも読めるため、両方を試して一意に決まれば自動採用、複数残れば選択画面を出します。当てはまらなければ短期E型（要協議）。C型は1学期期末試験の終了日より後の出発ならC-2、それ以前ならC-1（手動切替可）。
